01

Social media sizes

The current sizes for every placement worth designing for. Tap any row to copy “width × height” to the clipboard — the aspect ratio is there so you can set up the artboard without doing the maths.

02

Print bleed calculator

The number that causes the most reprints. Set your trim size and the bleed, and this gives you the document size to create, the safe area to keep text inside, and the pixel count at your export resolution.

03

Contrast checker (WCAG)

Type a colour, or pick from the presets. The ratio is what accessibility guidelines use: 4.5:1 for body text, 3:1 for large text. If it fails here, it fails for a lot of people — including anyone reading your work on a phone in daylight.

    04

    px · rem · pt

    Type into any field and the others follow. Point sizes from a print spec, rem values for a stylesheet, pixels for a mockup — this is the conversion that keeps a type scale consistent across both.

    05

    Palette from one colour

    Pick a brand colour and get a usable ramp: five tints, the base, five shades, and three accents that are actually related. Each swatch shows its contrast against white and black, so you can see what will hold up as text before you commit.

    Tap any swatch to copy its hex.

    07

    File weight budget

    The quiet reason a portfolio feels slow. Set the pixel size and the size you want the file to be, and this tells you how many bits per pixel you have left — which is what decides whether the export will band and block or hold together.

    06

    What font is this, really?

    Paste any CSS font stack and this shows you exactly which face your machine resolves it to — the one that actually renders, not the first one you asked for. It is measured, not guessed: the text is drawn on a canvas in each candidate and compared against the generic fallback, so a face that is not installed cannot fake its way in. The line you are reading is set in this site's own stack — Bricolage Grotesque first, with Helvetica, Arial and sans-serif behind it — so the counts below are a live example, not a demo.

    Green = resolved here · grey = fell through. Every line is drawn in the face it names, so a fallback that looks wrong is a fallback that is wrong.

      08

      What's actually inside that export

      Drop an image and read it the way a proofer would: real dimensions, the DPI it will print at, whether it has transparency, how much of it is pure black and pure white, and — the one nobody checks — the ratio of noise to detail, which is what tells you whether a JPEG has been re-saved one time too many or a PNG was exported at the wrong size and upscaled. Nothing leaves this tab; the file is read in memory and forgotten.

      09

      A lockup you can actually hand over

      Type a name, pick a mark, and this writes a real, clean SVG — live text you can outline, a transparent background, and the exact spacing a lockup needs — plus the three arrangements a client always asks for after the fact. Four files, one click, no account and no watermark. It opens in Illustrator as editable shapes because that is what it is.
